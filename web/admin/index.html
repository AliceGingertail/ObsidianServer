Пиры (Peers)

Что такое Peer (Пир)?

Peer (Пир) — это устройство пользователя, подключенное к VPN-серверу. Каждый пир представляет собой отдельное клиентское подключение с уникальными ключами шифрования и IP-адресом.

  • Device Name — название устройства (например: "iPhone Ивана", "Рабочий ноутбук")
  • Protocol — протокол VPN (WireGuard или OpenVPN)
  • IP Address — внутренний IP-адрес устройства в VPN-сети
  • Active — статус активности подключения

При создании пира автоматически генерируются ключи шифрования и конфигурационный файл для клиента.

Настройки сервера

Справочник по настройкам VPN-сервера

WireGuard

WireGuard — это современный VPN-протокол с открытым исходным кодом. Он обеспечивает высокую скорость соединения и надежное шифрование.

  • Endpoint — публичный адрес сервера (IP или домен), к которому подключаются клиенты
  • Port — UDP-порт для WireGuard (по умолчанию 51820)
  • Subnet — внутренняя подсеть VPN (например, 10.13.13.0/24)
Ограничения
  • Max Peers Per User — максимальное количество устройств (пиров) на одного пользователя
Как изменить настройки?

Настройки сервера задаются через переменные окружения при запуске. Для изменения отредактируйте файл .env или docker-compose.yml и перезапустите сервер.

# Пример переменных окружения: WIREGUARD_ENABLED=true WIREGUARD_ENDPOINT=vpn.example.com:51820 WIREGUARD_PORT=51820 WIREGUARD_SUBNET=10.13.13.0/24 MAX_PEERS_PER_USER=5
